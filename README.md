# FloodSentinel — Interactive Prototype Dashboard

**Team VitaForge**  
SEVA FIRST Innovation Challenge 2026 | Diploma & Higher Education Track

## Overview
This is the interactive software prototype for **FloodSentinel** — a village-level flood early warning and resilient design system.

The dashboard demonstrates:

- GREEN → YELLOW → ORANGE → RED risk-state engine
- Water level + rainfall inputs with rate-of-rise logic
- Offline-capable deterministic rules
- Simulated siren + SMS alerts
- DrainWatch (drain blockage) window with maintenance tickets
- JalSetu (pressure/flow anomaly) window with zone-level tickets
- Action / ticket workflow

> **Note:** This is a software demonstration prototype. Hardware sensors, field deployment, and real community pilots are part of the planned development roadmap and have not yet been executed.
